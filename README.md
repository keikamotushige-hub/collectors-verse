# Collector's Verse

写真からコレクションの物語・愛着・シェア文を紡ぐアプリ。

**URL:** https://collectors-verse.vercel.app  

## 起動（ローカル）

```bash
pip install -r requirements.txt
set GEMINI_API_KEY=your_key
python app.py
```

http://127.0.0.1:5001
